# Controls

Every shortcut, on macOS and on Windows and Linux. The Keyboard Shortcuts window (⌘/) shows the same list, and the command menu (⌘K) runs any command by name.

## Library

| Action                            | macOS  | Windows / Linux |
| --------------------------------- | ------ | --------------- |
| Open a music folder (desktop app) | **⌘O** | **Ctrl+O**      |
| Scan the folder again             | **⌘R** | **Ctrl+R**      |

## Songs

| Action                 | macOS                   | Windows / Linux                         |
| ---------------------- | ----------------------- | --------------------------------------- |
| Play the selected song | **↩** or double-click   | **Enter** or double-click               |
| Move through the list  | **↑** **↓** **⇞** **⇟** | **Up** **Down** **PageUp** **PageDown** |
| First / last song      | **↖** **↘**             | **Home** **End**                        |

## Playback

| Action                                         | macOS   | Windows / Linux    |
| ---------------------------------------------- | ------- | ------------------ |
| Play or pause                                  | **␣**   | **Space**          |
| Next song                                      | **⌘→**  | **Ctrl+Right**     |
| Previous song (or back to the start after 3 s) | **⌘←**  | **Ctrl+Left**      |
| Skip forward 10 s                              | **⌥⌘→** | **Ctrl+Alt+Right** |
| Skip back 10 s                                 | **⌥⌘←** | **Ctrl+Alt+Left**  |
| Volume up                                      | **⌘↑**  | **Ctrl+Up**        |
| Volume down                                    | **⌘↓**  | **Ctrl+Down**      |

The media keys on the keyboard, headphones and the lock screen also play, pause and skip.

## View

| Action                 | macOS   | Windows / Linux |
| ---------------------- | ------- | --------------- |
| Show or hide the queue | **⌥⌘U** | **Ctrl+Alt+U**  |

## Help

| Action             | macOS  | Windows / Linux |
| ------------------ | ------ | --------------- |
| Keyboard Shortcuts | **⌘/** | **Ctrl+/**      |
| Command menu       | **⌘K** | **Ctrl+K**      |
| Close a dialog     | **⎋**  | **Esc**         |
