# Controls

Every shortcut, on macOS and on Windows and Linux. The Keyboard Shortcuts window (⌘/) shows the same list, and the command menu (⌘K) runs any command by name.

## Library

| Action                            | macOS  | Windows / Linux |
| --------------------------------- | ------ | --------------- |
| Open a music folder (desktop app) | **⌘O** | **Ctrl+O**      |
| Scan the folder again             | **⌘R** | **Ctrl+R**      |
| Settings                          | **⌘,** | **Ctrl+,**      |

## Browsing

| Action                       | macOS                     | Windows / Linux             |
| ---------------------------- | ------------------------- | --------------------------- |
| Songs                        | **⌘1**                    | **Ctrl+1**                  |
| Albums                       | **⌘2**                    | **Ctrl+2**                  |
| Artists                      | **⌘3**                    | **Ctrl+3**                  |
| Folders                      | **⌘4**                    | **Ctrl+4**                  |
| Back                         | **⌘[**                    | **Ctrl+[**                  |
| Forward                      | **⌘]**                    | **Ctrl+]**                  |
| Search the library           | **⌘F**                    | **Ctrl+F**                  |
| Clear the search and go back | **⎋** in the search field | **Esc** in the search field |
| Show or hide the sidebar     | **⌥⌘S**                   | **Ctrl+Alt+S**              |

Favourites, Recently Added and Most Played are under **Collections** in the sidebar, and in the command menu (⌘K).

## Songs

| Action | macOS | Windows / Linux |
| --- | --- | --- |
| Play the selected songs | **↩** or double-click | **Enter** or double-click |
| Move through the list | **↑** **↓** **⇞** **⇟** | **Up** **Down** **PageUp** **PageDown** |
| First / last song | **↖** **↘** | **Home** **End** |
| Select more songs | **⇧↑** **⇧↓**, ⇧-click or ⌘-click | **Shift+Up** **Shift+Down**, Shift-click or Ctrl-click |
| Select all the songs in the view | **⌘A** | **Ctrl+A** |
| Select the playing song | **⌘L** | **Ctrl+L** |
| Favourite the selected songs (or the song playing) | **⌥⌘F**, or the **♥** in the list or the now-playing bar | **Ctrl+Alt+F**, or the **♥** |
| Song Info: see and edit the tags of the selected songs | **⌘I** | **Ctrl+I** |

## Playback

| Action                                         | macOS    | Windows / Linux      |
| ---------------------------------------------- | -------- | -------------------- |
| Play or pause                                  | **␣**    | **Space**            |
| Next song                                      | **⌘→**   | **Ctrl+Right**       |
| Previous song (or back to the start after 3 s) | **⌘←**   | **Ctrl+Left**        |
| Skip forward 10 s                              | **⌥⌘→**  | **Ctrl+Alt+Right**   |
| Skip back 10 s                                 | **⌥⌘←**  | **Ctrl+Alt+Left**    |
| Volume up                                      | **⌘↑**   | **Ctrl+Up**          |
| Volume down                                    | **⌘↓**   | **Ctrl+Down**        |
| Shuffle on or off                              | **⌘S**   | **Ctrl+S**           |
| Loop this song on or off                       | **⌥⌘R**  | **Ctrl+Alt+R**       |
| Loop the queue on or off                       | **⌥⇧⌘R** | **Ctrl+Alt+Shift+R** |

Right-click a song, or the selected songs, for **Play**, **Play Next**, **Add to Queue**, **Add to Playlist…**, **Favourite**, **Song Info…**, **Go to Album** and **Go to Artist**, in the desktop app **Show in Finder** (**Show in File Explorer** on Windows, **Show in File Manager** on Linux), and inside a playlist **Remove from Playlist**. The Play and Shuffle buttons on an album, an artist or a folder play all its songs.

The media keys on the keyboard, headphones and the lock screen also play, pause and skip.

## View

| Action                 | macOS   | Windows / Linux |
| ---------------------- | ------- | --------------- |
| Show or hide the queue | **⌥⌘U** | **Ctrl+Alt+U**  |

## Queue

| Action                         | macOS                        | Windows / Linux                           |
| ------------------------------ | ---------------------------- | ----------------------------------------- |
| Move through Up Next           | **↑** **↓** **↖** **↘**      | **Up** **Down** **Home** **End**          |
| Play the song under the cursor | **↩** or double-click        | **Enter** or double-click                 |
| Remove the song from the queue | **⌫** or **⌦**, or its **×** | **Backspace** or **Delete**, or its **×** |
| Move a song                    | drag it                      | drag it                                   |
| Clear Up Next                  | **Clear**                    | **Clear**                                 |

## Playlists

| Action | macOS | Windows / Linux |
| --- | --- | --- |
| New playlist, with the selected songs | **⌘N** | **Ctrl+N** |
| Add the selected songs to a playlist | drag them onto it in the sidebar, or right-click › **Add to Playlist…** | the same |
| Take the selected songs out of the playlist | **⌫** or **⌦** | **Backspace** or **Delete** |
| Move songs in the playlist | drag them | drag them |
| Rename the playlist | right-click it › **Rename Playlist**, type, **↩** (**⎋** keeps the name) | the same, with **Enter** (**Esc** keeps the name) |
| Undo the last playlist change | **⌘Z** | **Ctrl+Z** |
| Redo it | **⇧⌘Z** | **Ctrl+Shift+Z** |

Right-click a playlist in the sidebar for **Play Playlist**, **Shuffle Playlist**, **Rename Playlist** and **Delete Playlist**. Deleting moves the file to Playlark's trash; Undo puts it back. Playlists are edited in the desktop app; a folder opened in the browser shows them but can't change them.
